# pts_bomber
### **Первый** SMS/звонки бомбер написанный на `Rust`.

Новости и успехи разработки в Telegram канале - [pts_bomber](https://t.me/pts_bomber)

## Рабочие российские сервисы
### SMS
1. 4 лапы
2. Mvideo
### Операторы
1. Megafon
2. t2
3. Yota
### Сервисные SMS
1. Telegram
2. spot.uz
### Звонки
1. DNS
2. Sunlight
3. Надежда Фарм
